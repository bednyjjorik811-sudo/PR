# Sequelize + SQLite

Консольное приложение на Node.js: подключение к SQLite через Sequelize, описание модели, создание таблицы, добавление записей и вывод выборки в консоль.

## Запуск

```bash
npm install
npm start
```

База данных создаётся в файле `database.sqlite` (он исключён через `.gitignore`). При каждом запуске таблица пересоздаётся (`sync({ force: true })`), поэтому данные не дублируются.

## Структура

- `database.js` — подключение к SQLite (экземпляр Sequelize).
- `models/Car.js` — модель таблицы `cars`.
- `index.js` — проверка подключения, синхронизация, вставка двух записей, выборка и вывод, закрытие соединения.

## Предметная область

Автомобили (таблица `cars`).

| Поле | Тип | Описание |
|---|---|---|
| `brand` | STRING, обязательное | Марка автомобиля |
| `model` | STRING, обязательное | Модель |
| `year` | INTEGER | Год выпуска |
| `price` | FLOAT | Цена в рублях |
| `isAvailable` | BOOLEAN | Доступен ли для продажи (по умолчанию `true`) |

Sequelize автоматически добавляет поля `id`, `createdAt` и `updatedAt`.
