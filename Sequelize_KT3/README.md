# Контрольная точка №3. Модели Sequelize

Вариант 3 из примеров — «Рецепты». Категория (`Category`) содержит несколько рецептов (`Recipe`). Каждый рецепт связан с одной категорией через внешний ключ `categoryId`.

## Запуск

```sh
npm ci
npm start
```

При каждом запуске `sync()` создаёт таблицы в SQLite в памяти, а `seed.js` добавляет 3 категории и 4 рецепта. Скрипт выводит результаты пяти запросов в консоль.

1. Все рецепты с категориями — `findAll({ include: ... })`.
2. Рецепты быстрее 30 минут — `findAll({ where: ... })` с `Op.lt`.
3. Рецепт по ID — `findByPk()`.
4. Добавление рецепта — `create()`. После запроса в базе 5 рецептов.
5. Все категории — `findAll()`.
